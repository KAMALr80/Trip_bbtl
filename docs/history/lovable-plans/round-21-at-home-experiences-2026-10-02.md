# Round 21: At Home experiences

A separate trip type ("At Home") built on top of what already exists. Invites, approval, vibes, 21+ rules, teams, game engine, no-repeat draws, credits, call link and Test Lab are reused, not copied.

## What people will see

**Start (4 taps):** "🏠 Start an At Home experience" button on Home and in the trip switcher (beta-access users only). The steps are destination (Thailand / Mexico / Japan), then length (Weekend Fri–Sun, 1 week, 2 weeks), then start date (Weekend only lets you pick Fridays), then vibe. Prices show on the setup screen ($5.99 for 1–6 people, $8.99 for 7–12, max 12). After that comes checkout, then invite. It has no flights, stays, itinerary or trip time zone. Times show in each person's own zone.

**Checkout (also used for real-trip unlocks):** order summary (destination/length or trip length, size tier, list price, discount, total). Next is a Payment step showing "Beta pass — $0 today, no card needed" with a Continue button. Then a receipt. There are no card or bank fields anywhere.

**Pacing (made automatically from templates):**
- Weekend: Fri Takeoff + call game night, Sat cook-off/order-in + question vote, Sun build challenge + Passport Night.
- 1 week: Takeoff, 2 light weekday drops, weekend events, Passport Night.
- 2 weeks: same pattern over two weekends, about 8 activities max.
- Weekday drops happen at most every other day and take under 5 minutes. Questions run 1–2 per week: everyone answers, everyone votes, the Captain taps Reveal.
- Activities unlock each morning in the viewer's own zone. Weekend event cards show an optional "You might want" line 2 days early.
- The Captain can move a game night's date/time.

**Takeoff:** boarding-pass reveal per player, playlist drop, kickoff call.
**Passport Night:** recap plus a light "MVP of the trip" (wins + vote results). It shows only inside that experience.
**Voting:** existing one-tap vote, Captain "Reveal" (optional timer), or "Mark winner" for in-person games.
**Solo:** works with 1 person. Votes and MVP hide automatically.
**Keepsake:** when it ends, every member keeps it in their history and gets a destination postcard sticker.

**Look:** 4 new illustrations in the current cartoon style: a living room turned departure lounge, plus a skyline postcard for each of Thailand, Mexico and Japan. Boarding passes and postcards are drawn as styled cards.

**Rewards (Me > Rewards):**
- Returning At Home discount: $1 off every At Home purchase after your first.
- Captain reward code: when a real, non-sandbox trip ends, its Captain gets one $2 code (single use, 90 days, max one unused at a time).
- Only one discount per order. The server picks the larger one.

**Not competitive:** At Home never counts toward scores, leaderboards, Captain badges, levels or stats. The server enforces this.

**Test Lab:** At Home presets for each destination × length, with bots that answer and vote.

## Technical section

- `trips.kind` ('trip' | 'at_home'), `at_home_length`, `at_home_pack`. At Home trips are created with `season_scoring=false`. `trip_timezone` mirrors home and is unused.
- `at_home_packs` + `at_home_pack_items` (pack, category, text, easy_option, no_alcohol_option, adult flag), seeded in the migration with Thailand/Mexico/Japan content. Draws go through the existing content_seen no-repeat path and AI top-up (clean prompt, adult only via existing Party + 21+ checks, never for teens).
- `at_home_activities` (trip, day_date, kind, payload, starts_at nullable for calls), generated by `trip_private.plan_at_home` from the templates. Member-readable only once the viewer-local date is reached. "You might want" is exposed 2 days early through a member RPC.
- Questions reuse `weekly_questions`/`qotw_action`/`vote_weekly_answer` (1–2 per week rows). Mark winner reuses `save_game_scores`. MVP is computed on read in an RPC, never stored.
- `orders` table (trip, captain, kind, tier, list_cents, discount_cents, discount_source, amount_cents, status 'beta_free'|'paid', created_at). It is written only by a `checkout_beta` private function called from an authenticated server function. Price and discount come from the server, and the unlock reads from the order. A trigger on approval recalculates the tier when the group passes 6 before start and logs the difference.
- The real-trip unlock goes through the same `checkout_beta` (wraps the existing `trip_price`/`unlock_trip`). Siam Vibes is not touched.
- `reward_codes` (user, code, cents=200, expires_at, used_order). It is issued in `end_trip` for non-sandbox real trips, with a unique partial index for one unused code per user.
- `finalize_season`, `game_board`, `my_passport`, Captain badge counts and `my_unlocked_trips` skip `kind='at_home'`. `postcard_stickers` (user, trip, pack) are granted on end.
- Member cap of 12 for At Home in `join_trip`/`approve_member`.
- `lab_create` gets `p_kind`/`p_pack`/`p_length`, and `lab_as` answer/vote bots work unchanged.
- UI: `AtHomeSetup.tsx`, `Checkout.tsx` (shared with TripUnlock), `AtHomePlay.tsx` (Play tab branch inside Game Day), `Rewards` in MeExtras, plus a Home button and trip-switcher entry.
